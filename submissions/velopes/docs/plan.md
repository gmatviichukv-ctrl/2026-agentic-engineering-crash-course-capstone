# План реалізації

Порядок навмисний: специфікація → харнес → **червоні тести** → логіка циклом агента → UI → рев'ю окремим агентом.

| Крок | Що | Як перевіряється |
|---|---|---|
| 1 | `docs/spec.md`, `docs/plan.md` (цей коміт) | порядок комітів: spec раніше за код |
| 2 | Каркас Next.js + Vitest, `AGENTS.md`, хуки з демо дня 1 (захист `.env`, журнал дій) | `pnpm check` зелений на порожньому проєкті; `pnpm hooks:selftest` |
| 3 | Тести для F1–F4 **без реалізації** | `pnpm test` червоний — окремий коміт |
| 4 | `scripts/agent-loop.sh`: `pnpm check` → якщо червоне, передає вивід headless-агенту → повтор, ліміт ітерацій | лог прогону в `docs/runs/` |
| 5 | UI + `POST /api/bookings` | тест маршруту; ручна перевірка в браузері |
| 6 | Рев'ю окремою сесією (`.claude/agents/reviewer.md`), вивід у `docs/reviews/` | список знахідок + коміти з виправленнями |
| 7 | Журнал довіри, опис PR | людина перечитує і править |
