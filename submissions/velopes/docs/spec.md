## Функціональні вимоги

### ~~F1. Пошук оголошень~~ — вилучено у v2 (рішення людини). Код і тести F1 видалено разом із фічею.

### F2. Ціна оренди (`lib/rental.ts`)

- дати `from`/`to` — календарні дні, **обидва включно** (з 1 по 3 = 3 дні);
- ціна = (ціна велосипеда за день + сума цін екіпірування за день) × днів;
- **7 днів і більше → знижка 10 %** на весь підсумок;
- результат округлюється до цілих центів; рахуємо в центах, щоб не ловити похибки float;
- *(v1.1)* знижка округлюється до цента **окремо** (половина цента — на користь клієнта), підсумок = сума − знижка.

### F3. Валідація бронювання

- `to >= from`; `from` не раніше «сьогодні» (сьогодні передається параметром — для тестів);
- максимум 30 днів;
- екіпірування з `requiresHitch: true` (причіп) — лише до велосипеда з `trailerHitch: true`;
- одне й те саме екіпірування двічі в одному бронюванні — помилка.

### F4. Доступність

- два інтервали перетинаються, якщо мають хоч один спільний день (включно);
- велосипед вільний, якщо немає жодного бронювання цього велосипеда, що перетинається;
- *(v1.1)* перевірка доступності і збереження виконуються атомарно: два одночасні запити не можуть обидва пройти;
- екіпірування вільне, якщо кількість бронювань, що перетинаються і містять його, `< quantity`.

### F5. UI

- *(v2)* `/` — оренда: список велосипедів; форма: дати + чекбокси екіпірування → показує ціну
  і помилки валідації/доступності, кнопка «Забронювати»;
- `POST /api/bookings` — валідує (F3 + F4) і зберігає; повертає `201` з бронюванням або `400`/`409` з повідомленням українською.

- *(v2)* на тій самій сторінці — блок «Прокати поруч» (F6): кнопка «Моя геолокація» або вибір міста → список
  з назвою, адресою, відстанню і посиланням «Відкрити в Google Maps».

### F6. Прокати поруч — Google Places (v2)

- `lib/places.ts` (чисті функції, без мережі):
  - `buildPlacesRequest({ lat, lng, radiusM })` → тіло для `POST https://places.googleapis.com/v1/places:searchText`:
    `textQuery: "прокат велосипедів"`, `languageCode: "uk"`, `pageSize: 10`,
    `locationBias.circle` з центром і радіусом (за замовчуванням 5000 м, межі 100–50000);
    field mask: `places.id,places.displayName,places.formattedAddress,places.location,places.googleMapsUri`;
  - `parsePlaces(json, origin)` → `Shop[]` (`id, name, address, lat, lng, mapsUrl, distanceKm`), відсортовано
    за відстанню; записи без назви або координат пропускаються; `{}` (Google нічого не знайшов) → `[]`;
  - `distanceKm(a, b)` — формула гаверсинуса, округлення до 0,1 км;
  - `validateCoords(lat, lng)` — широта −90…90, довгота −180…180, обидва числа; інакше помилка українською.
- `GET /api/shops?lat=…&lng=…`:
  - немає `GOOGLE_MAPS_API_KEY` у середовищі → `503` «Пошук прокатів вимкнено: не задано ключ Google»;
  - некоректні координати → `400`;
  - Google відповів помилкою або не відповів за 5 с → `502`, без витоку ключа чи тіла помилки Google;
  - інакше `200 { shops }`.
- Ключ читається лише на сервері, у браузер не потрапляє. `.env.example` містить порожній `GOOGLE_MAPS_API_KEY=`;
  справжній ключ людина кладе в `.env` сама (агенту `.env` заборонено).
- Тести не ходять у мережу: `fetch` підміняється, відповідь Google — записаний приклад у `lib/__fixtures__/`.
